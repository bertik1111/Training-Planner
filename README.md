## Описание проекта

**Training Planner** - это графическое приложение (GUI) для планирования и учета тренировок. Приложение позволяет удобно добавлять, просматривать, фильтровать и хранить информацию о тренировках.

### Основные возможности

✅ **Управление тренировками**
- Добавление новых тренировок с указанием даты, типа и длительности
- Удаление существующих тренировок
- Просмотр всех тренировок в удобной таблице

✅ **Фильтрация**
- Фильтрация по типу тренировки (Бег, Плавание, Велосипед, Силовая, Йога, Футбол, Теннис)
- Фильтрация по дате в формате ГГГГ-ММ-ДД
- Сброс фильтров одним кликом

✅ **Валидация данных**
- Проверка правильности формата даты
- Проверка длительности (положительное число, не более 1440 минут)
- Проверка заполнения всех полей

✅ **Работа с данными**
- Автоматическое сохранение данных в JSON файл
- Ручное сохранение в JSON
- Загрузка данных из JSON файла

✅ **Дополнительные функции**
- Статистика тренировок (общее количество, длительность, распределение по типам)
- Меню приложения
- Статусбар с информацией о действиях

## Технические требования

- **Python** 3.6 или выше
- **Tkinter** (входит в стандартную библиотеку Python)
- **JSON** (встроенный модуль)
